# SmartBilling

SmartBilling is a Django-based billing and inventory management system designed to manage products, customers, invoices, payments, sales history, and reports in one application.

## Features

- User Signup and Login
- Dashboard with business summary
- Product Management
- Customer Management
- Invoice Creation
- Automatic Stock Reduction
- Payment Management
- Pending / Partial / Paid Invoice Status
- Sales History
- Reports and Date Filters
- CSV Report Export
- Company Settings and Profile Management
- Invoice PDF Download
- Print Invoice

## Technology Stack

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
- Bootstrap / Custom CSS
- ReportLab
- Git
- GitHub
